assets/icons/
=============

favicon.svg    - browser tab icon (referenced by every page)
icon-192.svg   - large app icon / apple-touch-icon

The interface itself uses emoji and CSS-drawn shapes rather than a sprite
sheet, so there is nothing else to build here. If you want a custom icon set,
add the files and reference them from the <head> of each HTML page.

The gradient used across the app:

    #00F5FF  (primary)   ->  #2F8BFF  ->  #7B61FF  (secondary)

Background: #09090B
