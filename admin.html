Advertising

Turn ads on, paste the official publisher snippet, and switch placements on or off. No file editing required.

Advertising policy reminder

  • Only paste the exact code your ad network gave you in your publisher dashboard. TAPX never generates ad code.
  • Ads are visible containers only. There are no hidden iframes, no invisible windows and no auto-refresh loops.
  • No ad is loaded, requested or refreshed on a tap. Tapping the game button never triggers an ad.
  • A saved snippet is rendered exactly once per page load. It is never re-injected, so a refresh cannot double-count an impression.
  • No impressions, clicks or earnings are simulated anywhere in this application.
  • This panel cannot manufacture ad activity. It only stores your own network's code and switches containers on or off.
  • All impressions, clicks and revenue are reported by the network's own code and visible in the network's publisher dashboard.

Master switch

The single switch that turns every placement on or off, instantly, without touching any file. With it off no ad renders anywhere, even if placements and code are saved below.

Security notes

  • Admin access is decided by the admin_users table and Row Level Security, verified on the server with is_admin(). There is no email check and no client-side flag.
  • Every privileged operation runs inside a SECURITY DEFINER function that calls require_admin() first.
  • The Supabase service_role key is never used by this frontend and must never be added to any file in this project.
  • Adsterra private credentials are never used by this frontend.
